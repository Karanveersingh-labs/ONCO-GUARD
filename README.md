# ONCO-GUARD

> **Scope and limitations:** This is an exploratory, self-directed computational biology learning project. It has not been experimentally validated and should not be interpreted as evidence of drug efficacy, binding affinity, safety, or clinical utility.

ONCO-GUARD is an exploratory computational biology project completed during my early undergraduate training. Using KRAS G12C as a case study, I developed a reproducible workflow to learn protein preparation, docking, molecular dynamics setup, and in silico ADMET assessment. This work is intended as a learning exercise and should not be interpreted as experimentally validated biological evidence or a drug-discovery claim. I am seeking mentorship to deepen my understanding of computational structural biology and translational cancer research.

**What I built / learned:** structural preparation of 4LUC (a KRAS G12C-related PDB structure used as starting point), docking workflow design with AutoDock Vina, initial MD setup and interpretation in GROMACS, in silico ADMET predictions, and reproducible documentation in Python/Bash/Jupyter.

**What remains uncertain:** No experimental validation, no binding data, MD metrics are setup-specific, free-energy analysis incomplete, ADMET is predicted only.
