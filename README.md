# ONCO-GUARD

I am Karanveer Singh, a first-year B.Tech Biotechnology student at SGGSWU, Punjab. I am building this project as an independent exploration of computational oncology and structure-based drug design. My goal is to learn reproducible workflows in molecular modeling, docking, and in silico analysis, while developing a careful understanding of uncertainty, validation, and scientific interpretation.

This repository documents an exploratory pipeline for KRAS G12C-related ligand analysis with limited computational resources. I am not claiming therapeutic or clinical relevance. The work is intended as a learning project and a platform for feedback.

Archived: DOI 10.5281/zenodo.22843776 (v23.0) | Concept: 10.5281/zenodo.22711779

### 1. What I am Learning
Reproducible molecular modeling, docking, trajectory analysis, and in silico ADMET workflows.

### 2. What I Have Done
- Target: PDB ID 4LUC (KRAS G12C)
- Docking: AutoDock Vina, Box [4.645, -14.532, 46.621]
- Dynamics: GROMACS workflow exploration
- 46 notebooks in 23 phases (V1/V2 iterations)

### 3. Exploratory Observations
All values are computational and hypothesis-generating only.

### 4. Limitations
No experimental validation. Force field, equilibration, replicates, and uncertainty not fully characterized.
